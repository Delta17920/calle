CALL-E

One on-call. No borders.
Your incident response, automated.

Catalog of on-call failures. CALL-E pages you. You say a short line. The runbook command is recorded.

This hosted page is the demo. It does not place live phone calls. To run a real CALL-E call, clone the repo, add your CALLE_API_KEY and ONCALL_PHONE in .env, then npm install and npm start on your machine.
